# Participant Guide

## Goal

Use the shared **DIAD semantic model** to create a thin report, validate permissions, and assess change impact.

## Timebox

40 minutes total.

## Tasks

### Task A — Reuse decision (7 min)

Using the scenario card, decide:

- Reuse model
- Extend model
- New model

Record your rationale in `templates/decision-log.md`.

### Task B — Build thin report (12 min)

1. Connect to shared DIAD semantic model.
2. Build one report page with:
   - KPI card (official measure)
   - trend visual (time)
   - breakdown visual (region/product)
   - one slicer
   - one interaction

### Task C — Consistency proof (6 min)

Answer 2 KPI questions and show they use DIAD official measures.

### Task D — Permissions test (8 min)

For each role/account provided, test:

- view
- edit
- build
- reshare

Fill `templates/permissions-matrix.csv`.

### Task E — Change-impact response (5 min)

Complete `templates/change-impact-response.md` after facilitator announces a central KPI definition change.

### Task F — Submit (2 min)

Submit:

1. Decision log
2. Permission matrix
3. Change-impact response
4. Link/screenshot of your thin report page
