# Shared Model Reuse Lab (DIAD)

A 35–45 minute hands-on lab for teaching teams how to reuse a shared semantic model in Power BI/Fabric with governance, permissions, and change-impact discipline.

## Lab outcomes

Participants will:

1. Decide when to reuse a shared model vs create a new one.
2. Build a thin report using the DIAD semantic model.
3. Prove KPI consistency from central measures.
4. Validate role/permission behavior.
5. Assess downstream impact of central model changes.

## Recommended duration

- **Target:** 40 minutes
- **Range:** 35–45 minutes
