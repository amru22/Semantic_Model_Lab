# Scoring Rubric (20 points)

## 1) Reuse decision quality (4)

- 0: No clear rationale
- 2: Partial rationale
- 4: Clear, evidence-based rationale across domain/security/grain

## 2) Thin report correctness (4)

- 0: Not based on shared model
- 2: Partially correct
- 4: Fully thin report on DIAD semantic model

## 3) KPI consistency proof (4)

- 0: No proof
- 2: Weak proof
- 4: Clear proof official measures were used

## 4) Permission matrix accuracy (4)

- 0: Incorrect/blank
- 2: Partial
- 4: Accurate role behavior captured

## 5) Change-impact response quality (4)

- 0: No practical response
- 2: Partial
- 4: Practical test + comms + go/no-go response
